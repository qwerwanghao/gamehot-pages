卡普空《异域龙潮》宣布2027年9月底停运，本体与DLC将下架

卡普空宣布线上专用团队对战游戏《异域龙潮》（Exoprimal）将于2027年9月底终止服务（9月29日或30日，因时区而异），停服后玩家将无法再启动和游玩这款游戏。官方未说明停运原因，并向玩家致谢和致歉。 该作为需常驻联网、无离线模式的团队对战动作游戏，2023年7月14日登陆PS5、Xbox Series、PS4、Xbox One和PC，评价褒贬不一。生存通行证高级档位已自2026年11月25日起停售；游戏本体及含DLC在内的所有商品将于2027年3月底从各商店下架，已购内容在停服前仍可下载并在线游玩。 2024年7月第4赛季结束后，官方已宣布不再推出新内容，此次停运意味着游戏约四年两个月的营运就此收尾。

    Take-Two 向 GitHub 提交 DMCA 下架通知，删除了非官方《GTA 6》PC 移植项目 Project Leonida 的主仓库及其约 2900 个 fork，共 3007 个仓库；项目的 17.9 万成员 Discord 服务器也无法访问，相关讨论帖因版权方举报被移除。项目此后终止，至少两名负责人宣布退出，创建者 NotRexed 称将专注学业，其后又在 X 表示 Leonida 并未死去、仍在幕后开发。该协议由 15 岁开发者 NotRexed 发起，目标是将泄露的《GTA 6》Xbox 版重编译后在 Windows 上原生运行；下架前有视频显示游戏已在 PC 上运行，渲染正常但帧率不足 5fps。Take-Two 称该项目助长了对《GTA 6》的版权侵权，并驳回了自带文件辩护，称所需文件来自 Cyberleek 泄露的未经授权 Xbox 构建版本。早期报道曾称下架疑似出自 Rockstar，后续披露的 DMCA 通知确认行动方为其发行商 Take-Two。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
