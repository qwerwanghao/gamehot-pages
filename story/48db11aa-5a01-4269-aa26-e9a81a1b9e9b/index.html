AI 综述

Take-Two 向 GitHub 提交 DMCA 下架通知，删除了非官方《GTA 6》PC 移植项目 Project Leonida 的主仓库及其约 2900 个 fork，共 3007 个仓库；其 17.9 万成员的 Discord 服务器也无法访问。项目创建者、15 岁开发者 NotRexed 一度宣布退出并称将专注学业，其后又在 X 表示 Leonida 并未死去、仍在幕后开发，并称 Take-Two 尚未直接联系本人。Take-Two CEO Strauss Zelnick 表示公司正加强技术防御和法律行动应对 AI 逆向工程。 该项目旨在将泄露的《GTA 6》Xbox 版重编译后在 Windows 上原生运行；下架前有视频显示游戏已在 PC 上运行，渲染正常但帧率不足 5fps。Take-Two 称该项目助长了对《GTA 6》的版权侵权，并驳回了“用户自带文件”的辩护，称所需文件来自 Cyberleek 泄露的未经授权 Xbox 构建版本。早期报道曾称下架疑似出自 Rockstar，后续披露的 DMCA 通知确认行动方为其发行商 Take-Two。
