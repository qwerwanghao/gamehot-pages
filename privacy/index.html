隐私说明

使用本站不需要注册或登录，不设置追踪性质的广告 Cookie。我们只处理让网站正常运行、处理反馈所必需的最少信息，不出售任何用户数据。

1. 浏览器本地数据

收藏夹、已读状态、深浅色与字体偏好、最近搜索记录（最多 10 条）、更新日志已读版本与未提交的反馈暂存内容仅保存在你当前浏览器的本地存储中；返回列表时的滚动位置与折叠状态仅保存在当前标签页的会话存储中，关闭标签页即清除。这些数据不会主动发送至服务器，清除浏览器存储后会一并删除，可在“收藏”页手动导出或导入。

2. 反馈提交

当你在动态站点使用反馈功能时，你主动填写的反馈内容、选填联系邮箱、提交时所在页面地址及可选截图会被保存用于问题核实与回复。为防止刷屏与接口滥用，服务会在短周期内通过网络地址与请求特征计算不可逆摘要以实施限流与封禁拦截，不用于个人画像或跨站追踪。公开静态快照版（GitHub Pages）不提供在线反馈表单。

3. 服务器与静态托管日志

GAMEHOT 不接入任何第三方访客统计脚本，不采集广告追踪标识。

  • 源站服务：仅出于安全防护、故障排查与限流需要记录短期基础 HTTP 访问日志（请求路径、响应码、时间与脱敏/临时源地址），过期自动轮转清理。
  • GitHub Pages 静态站点：公开静态快照托管于 GitHub Pages 基础设施，其边缘节点与访问日志遵循 GitHub 官方隐私声明的约束与留存策略。

4. 第三方内容与外链

本站展示公开新闻摘要、Steam 公开商店排行快照及权威媒体评测入口。点击跳转商店页面、评测原文或媒体站点后，你将离开本站，后续访问受对方网站隐私政策约束。

5. 联系与权利行使

如对本说明有疑问，或希望查询、更正、删除你此前通过站内提交的反馈记录，请通过或 GitHub Issues（https://github.com/qwerwanghao/gamehot-pages/issues）与我们联系，我们将在核实后及时处理。
