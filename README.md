# GAMEHOT

**值得关注的游戏动态。**

[打开 GAMEHOT](https://qwerwanghao.github.io/gamehot-pages/)

GAMEHOT 是一个中文游戏资讯站，关注全球 PC、主机和手游的发售、更新、平台优惠及行业动态。站点从平台、厂商公告和游戏媒体收集公开信息，整理成中文摘要，帮助读者快速了解正在发生的事。

## 在这里可以做什么

- 浏览精选、全部动态与热点，查看同一事件的不同报道。
- 搜索已收录的资讯，按主题浏览，并阅读日报、周报与月报。
- 收藏感兴趣的内容；收藏和阅读状态保存在当前浏览器，不会自动同步到其他设备。
- 通过文章中的原文链接回到信源，了解完整背景。
- 在“喜加一”查看免费活动与 Steam 国区价格；ITAD 历史最低记录和本站跟踪最低价分开显示，缺少记录时不猜价格。

报告以实际发布内容为准。摘要经过自动处理，可能存在错误或遗漏；涉及发售时间、价格等信息时，请以原始来源为准。

## 关于本仓库

本仓库存放 [GAMEHOT 网站](https://qwerwanghao.github.io/gamehot-pages/)的静态页面和资源，由服务器定期生成并发布。它是**发布产物，不是应用源码**；采集、模型处理、数据库和管理后台不在本仓库中。静态站的部分功能与动态站不同，仍在逐步完善。

仓库内容会在自动发布时被更新，请不要直接在这里编辑页面或资源；修改可能被下一次发布覆盖。

## 来源与致谢

GAMEHOT 基于 [AIHOT](https://github.com/KKKKhazix/AIHOT) 开源框架构建。新闻原文、图片及其他来源内容的权利归各自权利人所有；本站摘要和链接用于资讯整理与导读。

Steam 国区历史价来自 [IsThereAnyDeal](https://isthereanydeal.com/) 收录的 Steam 中国区 CNY 记录，展示其低价发生日期和来源链接，不代表已覆盖发售以来全部历史。本站与数据提供方没有隶属关系；购买价格以 Steam 结算页为准。
